# OGP fonts

Source: https://github.com/google/fonts/tree/main/ofl/notosansjp
License: SIL Open Font License 1.1 (see OFL.txt).

Derived from NotoSansJP[wght].ttf using fontTools.varLib.instancer at weights 400 and 900. The font families were renamed to “OGP Noto Regular” and “OGP Noto Black”. Fixed instances avoid variable-weight renderer differences. These files are build inputs only, not web fonts. Python/fontTools is not needed for normal builds.
